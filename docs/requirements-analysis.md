## 1. 项目概述

### 1.1 产品定位

一个公开可访问、单作者维护的个人技术博客，承担两个作用：

1. **技术沉淀**：系统记录 Python、FastAPI、智能体开发、计算机网络、数据结构等学习与实践。
2. **求职作品集**：通过文章、项目档案与工程过程，向招聘者证明需求分析、架构设计、实现、测试、部署与维护能力。

### 1.2 核心目标

- 让访客进入首页后快速理解作者的学习方向与写作主题。
- 让招聘者在少量点击内看到项目、个人职责、代码仓库、演示地址与复盘文章。
- 让作者不修改代码即可完成文章、项目与关于页的日常更新。
- 让已发布内容具备可被抓取、可被索引的基础 SEO 能力。
- 以单机、低预算、低维护的方式稳定运行。

### 1.3 成功标准

- 首页首屏包含站点主题、作者简介摘要、最新文章与分类入口。
- 从首页到任一项目详情不超过 2 次点击；从项目详情可到达关联复盘文章。
- 文章从创建到发布全流程可在后台完成，无需改代码或重新部署。
- 已发布文章、项目与关于页可被搜索引擎抓取；草稿与后台不可被索引。
- 核心用户流程具备自动化测试，主分支通过 CI 后可部署。
- 上线后在无专职运维的情况下可长期运行。

## 2. 用户角色与权限

### 2.1 角色定义

| 角色 | 定义 | 核心诉求 |
|---|---|---|
| 访客 | 未登录的公开访问者，包括普通读者、同行与招聘者 | 快速了解作者、阅读文章、查看项目与联系方式 |
| 管理员 | 唯一登录后台的作者 | 写作、发布、维护项目与关于页 |
| 搜索引擎爬虫 | 非人类访问者 | 抓取并索引已发布公开内容 |

### 2.2 权限矩阵

| 能力 | 访客 | 管理员 |
|---|---|---|
| 浏览已发布文章、项目、关于页 | 允许 | 允许 |
| 搜索、分类/标签筛选、归档 | 允许 | 允许 |
| 复制链接、系统分享 | 允许 | 允许 |
| 查看草稿或已撤回文章 | 禁止 | 允许（仅后台预览） |
| 登录后台 | 禁止 | 允许 |
| 文章、项目、关于页的创建/编辑/删除 | 禁止 | 允许 |
| 图片上传 | 禁止 | 允许 |
| 修改管理员密码 | 禁止 | 允许（需验证当前密码） |

### 2.3 非产品角色

- AI Agent 是研发过程协作者，不进入产品账号与权限体系。
- 搜索引擎爬虫按“公开只读”处理，不获得后台或草稿访问能力。

### 2.4 核心使用场景

1. **招聘者评估**：首页了解方向 → 项目列表 → 项目详情 → GitHub/在线演示 → 关联复盘文章。
2. **读者阅读**：首页或文章列表 → 分类/标签/搜索 → 文章详情 → 上一篇/下一篇。
3. **作者写作**：登录 → 新建文章 → Markdown 写作与图片上传 → 选择分类、标签与项目 → 预览 → 发布。
4. **作者维护**：项目管理中编辑项目信息；文章侧关联项目后，项目详情自动聚合；关于页编辑后前台即时更新。
5. **Agent 协作研发**：需求 → 设计 → 实现 → 测试评审 → 部署，过程产物可追溯，不进入产品功能。

## 3. 信息架构与页面需求

### 3.1 页面地图

```text
公开页面
├─ 首页
├─ 文章列表（全部 / 分类 / 标签 / 搜索结果）
├─ 文章详情
├─ 归档
├─ 项目列表
├─ 项目详情
├─ 关于
└─ 404 / 500

后台页面
├─ 登录
├─ 文章管理（列表）
├─ 文章编辑（新建 / 编辑 / 预览）
├─ 项目管理（列表）
├─ 项目编辑（新建 / 编辑）
├─ 关于页编辑
└─ 修改密码
```

说明：路径形式在技术设计阶段确定；本文档只约束页面职责与行为。

### 3.2 公共页面

#### 3.2.1 首页

**目标**：访客首屏理解“这个站点写什么、作者是谁、从哪里开始读”。

**内容**

- 站点名称。
- 个人简介摘要（来自关于页的“首页简介摘要”字段）。
- 最新 5 篇已发布文章。
- 3 个固定分类入口：技术文章、项目实践、学习复盘。
- 全站导航：首页、文章、项目、关于。

**文章卡片字段**：标题、摘要、发布时间、分类、标签。

**规则**

- 只展示已发布文章，按首次发布时间倒序。
- 无已发布文章时显示空状态，不出现空白区块。
- 项目入口位于全站导航；首版首页不设置精选项目、轮播或运营位。
- 首页可被搜索引擎索引。

#### 3.2.2 文章列表

**目标**：浏览全部文章，并通过分类、标签、搜索缩小范围。

**内容**

- 文章卡片：标题、摘要、发布时间、分类、标签。
- 筛选区：分类单选、标签单选、关键词搜索。
- 分页：每页 10 篇。
- 归档入口。

**规则**

- 只展示已发布文章，按首次发布时间倒序。
- 分类、标签、搜索条件可组合，结果取交集。
- 清空筛选后恢复全部文章。
- 无结果时显示空状态，并提供清空筛选入口。
- 页码超出范围返回 404。
- 分类筛选页可被索引；标签筛选与搜索结果页设置为 noindex，不进入 sitemap。

#### 3.2.3 文章详情

**目标**：完整、舒适地阅读一篇技术文章。

**内容**

- 标题、首次发布时间、分类、标签。
- Markdown 正文。
- 代码高亮。
- 文章目录（TOC），可跳转至对应标题。
- 上一篇/下一篇。
- 分享入口：复制链接、调用系统分享。
- 若文章关联项目，展示项目入口。

**规则**

- 仅已发布文章可访问；草稿、已撤回、不存在文章返回 404。
- 上一篇/下一篇按首次发布时间相邻的已发布文章计算；首篇/末篇隐藏对应入口。
- 已发布文章修改标题不改变 URL。
- 页面可被搜索引擎索引，具备独立标题、描述与分享卡片信息。
- 首版不提供评论、点赞、收藏。

#### 3.2.4 归档

**目标**：按时间回顾全部文章。

**内容**

- 按“年-月”分组，组内按发布时间倒序。
- 每组展示文章标题与发布时间。

**规则**

- 只使用已发布文章。
- 空月份不展示。
- 首版归档页不分页。
- 无文章时显示空状态。

#### 3.2.5 项目列表

**目标**：集中展示可验证的工程作品。

**内容**

- 项目卡片：名称、简介、封面、技术栈、项目状态。
- 进入项目详情的入口。

**规则**

- 按项目更新时间倒序。
- 封面缺失时显示统一占位图。
- 所有项目条目创建后即公开；首版不设项目草稿/隐藏状态（待确认）。
- 无项目时显示空状态。
- 首版不提供项目搜索与项目筛选。

#### 3.2.6 项目详情

**目标**：让招聘者理解项目背景、作者职责与工程难度。

**内容**

- 名称、封面、状态、简介。
- 背景、目标、功能、技术栈、架构说明。
- 个人职责、技术难点、解决方案。
- 演示地址、代码仓库地址。
- 关联的已发布复盘文章列表。

**规则**

- 空字段对应区块整体隐藏，不出现空标题。
- 关联文章只展示已发布内容；无关联文章时隐藏该区块。
- 演示地址与仓库地址使用合法 http/https URL；存在时以新窗口打开。
- 项目不存在时返回 404。
- 页面可被搜索引擎索引。

#### 3.2.7 关于

**目标**：用一页说明作者背景、方向、技术栈与联系方式。

**内容**

- 个人简介。
- 学习方向。
- 技术栈。
- 联系方式。
- 外部主页链接（如 GitHub）。

**规则**

- 展示后台最新保存的内容。
- 不做复杂个人档案系统、时间线、技能评分或简历生成器。
- 外部链接使用合法 http/https URL。
- 页面可被搜索引擎索引。

#### 3.2.8 404 与 500

- 404：访问不存在、已删除、草稿或已撤回内容时展示；包含返回首页、文章列表与搜索入口。
- 500：服务端异常时展示统一错误页；不暴露堆栈、路径或配置信息。
- 两类页面均返回正确 HTTP 状态码。

### 3.3 后台页面

#### 3.3.1 登录

- 字段：账号、密码。
- 成功后进入文章管理页。
- 失败显示通用错误，不提示账号是否存在。
- 连续 5 次失败锁定 15 分钟。
- 不提供注册、多用户、角色管理与自助找回密码。
- 登录页不可被搜索引擎索引。

#### 3.3.2 文章管理

- 列表字段：标题、分类、状态、首次发布时间、更新时间、操作。
- 状态筛选：全部 / 草稿 / 已发布。
- 操作：编辑、预览、发布/撤回、删除。
- 按更新时间倒序。
- 删除需二次确认。

#### 3.3.3 文章编辑

**字段**

- 标题（必填）。
- 摘要（发布时必填）。
- 正文 Markdown（发布时必填；草稿可为空）。
- 分类（必填，三选一）。
- 标签（可选，可多选或新建）。
- 所属项目（可选，最多一个）。

**操作**

- 保存草稿。
- 预览（仅管理员可见）。
- 发布。
- 保存更新（已发布文章）。
- 撤回为草稿。
- 删除。

**规则**

- 发布前校验标题、摘要、正文、分类。
- 已发布文章保存后立即生效。
- 首次发布时间在第一次发布时写入，之后撤回再发布不改变。
- 修改标题不改变文章 URL。
- 图片上传后可插入正文光标位置。
- 有未保存修改时离开页面需二次确认。
- 首版不提供自动保存、版本历史、定时发布、协同编辑。

#### 3.3.4 项目管理

- 列表字段：名称、状态、技术栈、更新时间、操作。
- 操作：新建、编辑、删除。
- 按更新时间倒序。
- 删除需二次确认，并说明“关联文章会保留，但会解除项目关联”。

#### 3.3.5 项目编辑

**字段**

- 名称（必填）。
- 简介（必填）。
- 个人职责（必填，多行文本）。
- 封面（可选）。
- 技术栈（可选，多项）。
- 状态（必填，进行中/已完成/已归档）。
- 背景、目标、功能、架构说明、技术难点、解决方案（可选，Markdown）。
- 演示地址、代码仓库地址（可选，合法 URL）。

**规则**

- 长文本字段支持 Markdown 与图片插入。
- 关联文章在文章侧维护：文章编辑时选择所属项目；项目详情自动聚合。
- 空字段对应前台区块隐藏。
- 首版不提供手动拖拽排序。

#### 3.3.6 关于页编辑

**字段**

- 首页简介摘要（必填）。
- 个人简介（必填）。
- 学习方向（可选）。
- 技术栈（可选，多项）。
- 联系方式（可选，多项：标签 + 值）。
- 外部主页链接（可选，多项：标签 + URL）。

**规则**

- 联系方式与外部主页链接至少填写一项。
- 简介与学习方向为多行纯文本，不支持页面搭建器。
- URL 必须是合法 http/https。
- 保存后覆盖旧内容，前台立即展示最新版本。
- 不提供版本历史与预览审批。

#### 3.3.7 修改密码

- 首版提供，已计入范围（原 Q-06 待确认项已确认，见 `docs/technology-decisions.md` ADR-05）。
- 需验证当前密码；新密码需满足强度要求并与确认密码一致；修改成功后旧密码立即失效。
- 不支持自助找回密码。
- 实现方式：复用 Django Admin 自带的密码修改功能。

## 5. 数据实体与关系

> 本节为概念数据模型，用于明确业务对象与规则，不代表数据库表结构。

### 5.1 实体定义

#### 5.1.1 管理员 AdminUser

| 字段 | 必填 | 规则 |
|---|---|---|
| 账号 | 是 | 全站唯一，首版仅一个管理员 |
| 密码凭证 | 是 | 不可逆存储，任何界面与日志不得出现明文 |
| 最近登录时间 | 否 | 登录成功后更新 |
| 创建/更新时间 | 系统 | 自动维护 |

规则：首版不区分角色，不建立多用户体系。

#### 5.1.2 分类 Category

| 字段 | 必填 | 规则 |
|---|---|---|
| 名称 | 是 | 固定为技术文章、项目实践、学习复盘 |
| 稳定标识 | 是 | 用于筛选与 URL |
| 展示顺序 | 是 | 固定顺序 |

规则：分类不可新增、改名、删除。

#### 5.1.3 标签 Tag

| 字段 | 必填 | 规则 |
|---|---|---|
| 名称 | 是 | 去除首尾空格；不区分大小写唯一；不超过 20 字 |
| 稳定标识 | 是 | 用于筛选与 URL |

规则：在文章编辑中创建与选择；首版不提供独立标签管理页。标签用于描述技术主题，例如 Python、FastAPI、Agent、RAG、计算机网络、数据结构。

#### 5.1.4 文章 Article

| 字段 | 必填 | 规则 |
|---|---|---|
| 标题 | 是 | 1–120 字 |
| 摘要 | 发布时必填 | 不超过 200 字；用于卡片与 SEO 描述 |
| 正文 | 发布时必填 | Markdown；草稿可为空 |
| 分类 | 是 | 三选一 |
| 标签 | 否 | 0..N；每个不超过 20 字；去重 |
| 所属项目 | 否 | 0..1；最多关联一个项目 |
| 状态 | 是 | 草稿 / 已发布 |
| 稳定标识 | 是 | 创建时生成，之后不变；用于稳定 URL |
| 首次发布时间 | 发布时写入 | 撤回/再次发布不改变 |
| 创建时间 | 系统 | 自动维护 |
| 更新时间 | 系统 | 自动维护 |

规则：文章可以无标签、无项目；必须有且仅有一个分类。三类分类共用同一文章实体、编辑流程、列表与详情页，不为单一分类单独开发内容系统。

#### 5.1.5 项目 Project

| 字段 | 必填 | 规则 |
|---|---|---|
| 名称 | 是 | 1–80 字 |
| 简介 | 是 | 不超过 200 字 |
| 个人职责 | 是 | 多行文本，不超过 500 字；说明本人负责的工作 |
| 封面 | 否 | 单张图片；缺失显示占位 |
| 技术栈 | 否 | 0..N；每项不超过 30 字 |
| 状态 | 是 | 进行中 / 已完成 / 已归档（待确认） |
| 背景 | 否 | Markdown |
| 目标 | 否 | Markdown |
| 功能 | 否 | Markdown |
| 架构说明 | 否 | Markdown |
| 技术难点 | 否 | Markdown |
| 解决方案 | 否 | Markdown |
| 演示地址 | 否 | 合法 http/https URL |
| 仓库地址 | 否 | 合法 http/https URL |
| 创建时间 | 系统 | 自动维护 |
| 更新时间 | 系统 | 自动维护 |

规则：项目创建即公开；详情页空字段区块隐藏。技术栈与长文本建议填写，但首版强制名称、简介、个人职责、状态。

#### 5.1.6 关于页 AboutPage

| 字段 | 必填 | 规则 |
|---|---|---|
| 首页简介摘要 | 是 | 不超过 200 字 |
| 个人简介 | 是 | 多行纯文本，不超过 2000 字 |
| 学习方向 | 否 | 多行纯文本，不超过 1000 字 |
| 技术栈 | 否 | 0..N；每项不超过 30 字 |
| 联系方式 | 否 | 0..N；标签 + 值 |
| 外部主页链接 | 否 | 0..N；标签 + 合法 URL |
| 更新时间 | 系统 | 保存后更新 |

规则：单例；联系方式与外部主页链接至少填写一项。

#### 5.1.7 图片资源 UploadedImage

| 字段 | 必填 | 规则 |
|---|---|---|
| 文件地址 | 是 | 上传后可公开访问 |
| 原始文件名 | 否 | 仅用于识别 |
| 文件类型 | 是 | JPG/PNG/WebP/GIF |
| 文件大小 | 是 | 不超过 2MB |
| 上传时间 | 系统 | 自动维护 |

规则：首版不提供媒体库界面；图片被文章/项目内容引用，不做强制关联。

### 5.2 实体关系

```text
Category 1 ──── N Article N ──── M Tag
                     │
                     │ 0..1（文章可选所属项目）
                     ▼
                 Project 1 ──── N Article
```

- 分类与文章：1:N。每篇文章必须属于一个分类。
- 文章与标签：N:M。文章可有 0..N 个标签。
- 项目与文章：1:N。一个项目可关联多篇文章；一篇文章最多关联一个项目，也可以不关联。
- 关于页：单例。
- 图片资源：被文章正文、项目长文本、项目封面引用；不做独立管理界面。
- 管理员：单例；首版不建立内容作者归属关系。

### 5.3 状态与生命周期

**文章状态**

| 当前状态 | 操作 | 结果 | 前台可见 |
|---|---|---|---|
| 草稿 | 发布 | 已发布，写入首次发布时间 | 是 |
| 已发布 | 撤回 | 草稿，保留首次发布时间 | 否 |
| 已发布 | 删除 | 删除 | 否 |
| 草稿 | 删除 | 删除 | 否 |
| 已发布 | 保存更新 | 内容即时更新，URL 与首次发布时间不变 | 是 |

**项目状态**：进行中、已完成、已归档仅作为展示标签，不构成发布流程。

**关于页**：保存即以新内容覆盖旧内容，无审批与版本历史。

## 6. 业务规则

| 编号 | 规则 |
|---|---|
| BR-01 | 分类固定为技术文章、项目实践、学习复盘，不支持增删改。 |

| BR-03 | 文章 URL 创建后保持稳定，修改标题不影响 URL。 |
| BR-04 | 首次发布时间以第一次发布为准；撤回后再次发布不改变首次发布时间。 |
| BR-05 | 只有已发布文章对访客可见；草稿与已撤回文章公开访问返回 404。 |
| BR-06 | 文章列表、搜索、归档、上下篇、项目关联文章与 sitemap 只使用已发布文章。 |
| BR-07 | 文章必须属于一个分类；可以没有标签；可以没有项目。 |
| BR-08 | 一篇文章最多关联一个项目；一个项目可关联多篇文章。 |
| BR-09 | 删除项目时文章保留、项目关联置空；删除文章时从项目关联列表移除。 |
| BR-10 | 文章列表与搜索结果每页 10 篇；归档首版不分页。 |
| BR-11 | 文章按首次发布时间倒序；项目按更新时间倒序。 |
| BR-12 | 归档按 Asia/Shanghai 时区的年月分组，组内按发布时间倒序。 |
| BR-13 | 搜索匹配标题、摘要、正文文本（去除 Markdown 标记），仅已发布；拉丁字母不区分大小写。 |
| BR-14 | 分类筛选单选、标签筛选单选；分类、标签、搜索可组合取交集。 |

| BR-16 | 项目创建即公开；首版不设项目草稿/隐藏状态（待确认）。 |
| BR-17 | 图片上传后可被 Markdown 引用；首版不做媒体库、图片删除与孤儿文件清理。 |
| BR-18 | 删除文章或项目需二次确认；首版无回收站，删除不可恢复。 |
| BR-19 | 全站界面语言为中文，不提供多语言切换。 |
| BR-20 | 未在本文档列出的功能默认不属于首版。 |

## 7. 异常场景与处理

| 编号 | 场景 | 预期处理 | 用户可见结果 |
|---|---|---|---|
| EX-01 | 未登录访问后台页面 | 重定向到登录页，不暴露后台内容 | 登录页 |
| EX-02 | 账号或密码错误 | 返回通用错误，不提示账号是否存在 | 明确的失败提示 |
| EX-03 | 连续 5 次登录失败 | 锁定 15 分钟，锁定期间正确密码也拒绝 | 锁定提示 |
| EX-04 | 会话过期 | 拦截操作并要求重新登录；有未保存修改时先提示 | 登录页或提示 |
| EX-05 | 表单校验失败 | 阻止保存，字段级提示 | 错误信息定位到字段 |
| EX-06 | 图片类型不支持或超过 2MB | 拒绝上传，保留编辑器内容 | 失败原因提示 |
| EX-07 | 图片上传网络中断 | 不插入无效链接 | 上传失败提示 |
| EX-08 | 保存请求失败 | 不清空编辑器内容，允许重试 | 保存失败提示 |
| EX-09 | 文章不存在、为草稿或已撤回 | 公开访问返回 404 | 404 页面 |
| EX-10 | 项目不存在 | 返回 404 | 404 页面 |
| EX-11 | 搜索或筛选无结果 | 显示空状态，提供清空条件入口 | 空状态 |
| EX-12 | 删除仍有文章关联的项目 | 二次确认；文章保留，项目关联置空 | 删除成功提示 |
| EX-13 | 删除项目关联的文章 | 从项目关联列表移除 | 删除成功提示 |
| EX-14 | 输入重复标签 | 复用已有标签，不创建重复项 | 标签正常选中 |
| EX-15 | 演示/仓库/外链 URL 非法 | 阻止保存并提示 | 字段级错误 |

| EX-18 | 页码超出范围 | 返回 404 | 404 页面 |
| EX-19 | 同一内容被重复编辑 | 单管理员场景，后保存覆盖先保存 | 最新保存结果 |
| EX-20 | 访问不存在的路径 | 返回 404 | 404 页面 |

## 8. 验收标准

### 8.1 公共阅读

**AC-01 首页**

- 展示站点名称、简介摘要、最新 5 篇已发布文章、3 个分类入口。
- 草稿不出现；无已发布文章时显示空状态。

**AC-02 文章列表与分页**

- 只展示已发布文章，按首次发布时间倒序，每页 10 篇。
- 卡片包含标题、摘要、发布时间、分类、标签。
- 分页可前后翻页；页码越界返回 404。

**AC-03 筛选组合**

- 分类、标签、搜索可任意组合，结果为交集。
- 清空条件后恢复全部文章；无结果时显示空状态。

**AC-04 搜索**

- 匹配标题、摘要、正文文本（去除 Markdown 标记）；只返回已发布文章。
- 拉丁字母大小写不敏感；空关键词不产生筛选。

**AC-05 文章详情**

- Markdown 正确渲染，代码高亮可用，目录可跳转。
- 展示发布时间、分类、标签；关联项目时展示项目入口。
- 草稿与已撤回文章返回 404。

**AC-06 上一篇/下一篇**

- 按首次发布时间相邻的已发布文章计算。
- 首篇隐藏“上一篇”，末篇隐藏“下一篇”，不跨越草稿。

**AC-07 归档**

- 只展示已发布文章，按年月倒序分组。
- 每组包含文章标题与发布时间；空月份不出现。

**AC-08 项目列表**

- 展示名称、简介、封面、技术栈、状态。
- 按更新时间倒序；封面缺失显示占位；无项目时显示空状态。

**AC-09 项目详情**

- 展示背景、目标、功能、技术栈、架构说明、个人职责、技术难点、解决方案、演示地址、仓库地址与关联已发布文章。
- 空字段区块整体隐藏；项目不存在时返回 404。

**AC-10 关于页**

- 展示最新保存的简介、学习方向、技术栈、联系方式与外部链接。
- 空字段不产生空标题；外链可正常打开。

### 8.2 后台管理

**AC-11 登录**

- 正确凭证进入后台；错误凭证显示通用错误。
- 连续 5 次失败锁定 15 分钟；登录页不被索引。

**AC-12 权限**

- 未登录访问任意后台页面均跳转登录。
- 访客无法通过 URL 访问草稿预览；退出后会话失效。

**AC-13 文章草稿**

- 新建文章标题必填；草稿允许摘要与正文为空。
- 保存后出现在草稿列表，前台不可见。

**AC-14 发布**

- 发布前校验标题、摘要、正文、分类。
- 发布后前台可见，并进入列表、归档与 sitemap。
- 首次发布时间写入；撤回再发布不改变该时间。

**AC-15 撤回与删除**

- 撤回后前台 404，并从列表、归档与 sitemap 移除。
- 删除需二次确认；删除后不可恢复；项目关联自动解除。

**AC-16 文章更新**

- 已发布文章保存后立即生效。
- 修改标题不改变 URL；首版无版本历史。

**AC-17 图片上传**

- 支持 JPG/PNG/WebP/GIF，单张不超过 2MB。
- 上传成功后可插入 Markdown；类型或大小不符时拒绝并提示；SVG 拒绝。

**AC-18 项目管理**

- 项目名称、简介、个人职责、状态为必填；可创建、编辑、删除项目。
- 删除需二次确认；删除后关联文章保留且所属项目置空，项目详情不再可访问并从 sitemap 移除。

**AC-19 关于页编辑**

- 管理员可编辑并保存；保存后前台刷新可见。
- 必填缺失或 URL 非法时阻止保存并提示；无版本历史。

**AC-20 修改密码**

- 需验证当前密码；新密码满足强度要求；修改成功后旧密码立即失效。
- 不支持自助找回密码。

**AC-21 未保存提示**

- 编辑器存在未保存修改时，离开页面弹出确认。

### 8.3 安全与数据一致性

**AC-22 密码安全**

- 明文密码不出现在界面、日志或代码仓库中；密码以不可逆方式存储。

**AC-23 写入安全**

- 后台写操作具备 CSRF 防护；Markdown 中的脚本或危险 HTML 不会执行。

**AC-24 上传安全**

- 校验真实文件类型与大小；文件名不可预测；上传目录不可执行脚本。

**AC-25 后台不可索引**

- 所有后台页面均禁止搜索引擎索引。

**AC-26 数据一致性**

- 每篇文章只能属于 3 个分类之一；标签不重复；文章最多关联 1 个项目。
- 删除项目不删除文章；删除文章会从项目关联中移除。

### 8.4 SEO、分享与异常

**AC-27 页面元信息**

- 首页、文章列表、文章详情、项目详情、关于页、归档与分类列表均有独立 title 与 description。
- 文章页具备 canonical 信息，分享卡片含标题、描述与链接。

**AC-28 sitemap**

- 包含首页、文章列表、文章详情、项目详情、关于、归档与分类列表。
- 不包含草稿、已撤回内容、搜索结果、标签筛选页与后台。

**AC-29 robots.txt**

- 允许抓取公开页面，禁止抓取后台，并声明 sitemap。

**AC-30 404**

- 已删除、已撤回、不存在内容返回 404 状态并显示友好页面。

**AC-31 分享**

- 复制链接有成功反馈。
- 支持系统分享时调用系统分享；不支持时回退为复制链接。

**AC-32 500**

- 显示友好错误页，不暴露堆栈、路径、配置或依赖信息。

**AC-33 空状态**

- 无文章、无项目、无搜索结果、无归档内容时均有明确空状态与下一步入口。

### 8.5 非功能验收

**AC-34 响应式**

- 360px 宽度下无横向溢出；代码块可横向滚动；导航与正文可读。

**AC-35 浏览器兼容**

- 最新两个版本的 Chrome、Edge、Firefox、Safari 可完成主要阅读流程。

**AC-36 可访问性**

- 标题层级语义正确；主要操作可键盘完成；图片有 alt；文本对比度满足基本可读。

**AC-37 性能**

- 文章图片懒加载；在目标服务器带宽条件下首屏可正常加载。
- 建议目标：4G 冷启动首屏可交互不超过 3 秒。

**AC-38 工程质量**

- 核心流程具备自动化测试；CI 在合并前执行 lint、测试与构建；主分支可部署。

## 9. 非功能需求

### 9.1 安全

- NFR-SEC-01：管理员密码不可逆存储，任何日志不得记录明文密码。
- NFR-SEC-02：后台会话具备有效期；退出登录立即失效。
- NFR-SEC-03：后台写操作具备 CSRF 防护。
- NFR-SEC-04：Markdown 渲染需净化危险 HTML，禁止脚本执行。
- NFR-SEC-05：上传文件需校验真实类型、大小与文件名；禁止 SVG。
- NFR-SEC-06：后台全部页面禁止搜索引擎索引；生产环境启用 HTTPS。
- NFR-SEC-07：密钥、数据库凭证等敏感配置不得提交到代码仓库。

### 9.2 SEO

- NFR-SEO-01：公开内容页具备独立 title、description 与语义化标题结构。
- NFR-SEO-02：文章 URL 稳定，修改标题不改变 URL。
- NFR-SEO-03：提供 sitemap 与 robots.txt。
- NFR-SEO-04：删除、撤回与不存在内容返回 404 状态。
- NFR-SEO-05：文章页提供 canonical 与分享卡片元信息。

### 9.3 性能

- NFR-PERF-01：移动端优先，适配 360px 及以上宽度。
- NFR-PERF-02：图片懒加载，避免首屏加载正文全部图片。
- NFR-PERF-03：在目标服务器带宽条件下，公开页面可正常访问；建议 4G 冷启动首屏不超过 3 秒。

### 9.4 兼容与可访问性

- NFR-UX-01：支持最新两个版本的 Chrome、Edge、Firefox、Safari。
- NFR-UX-02：正文、导航与代码块在移动端可读、可横向滚动。
- NFR-UX-03：标题层级、键盘操作、图片 alt、颜色对比度满足基本可访问性。

### 9.5 可维护性与工程

- NFR-ENG-01：核心流程具备自动化测试，覆盖登录、文章发布/撤回、项目关联、关于页保存与权限拦截。
- NFR-ENG-02：CI 在合并前执行 lint、测试与构建，失败则阻止合并。
- NFR-ENG-03：主分支保持可部署；部署流程可重复执行。
- NFR-ENG-04：需求、设计、实现、测试与评审产物可追溯，支撑 AI Agent 协作研发实践。

### 9.6 合规与运维

- NFR-OPS-01：部署在大陆服务器时，域名绑定需完成 ICP 备案；备案不作为首版交付的阻塞项，采用双阶段上线（先 IP 验收，决定公开时再备案并启用 HTTPS），见 `docs/technology-decisions.md` ADR-06。
- NFR-OPS-02：生产环境启用 HTTPS（阶段 B 起；阶段 A 仅内网/隧道访问后台）。
- NFR-OPS-03：数据备份方式已确认（阿里云文件备份 + 每夜 SQLite 在线备份 + 每月恢复演练，见 `docs/technology-decisions.md` ADR-08）；首版不提供站内导出功能。

### 9.7 部署与资源约束

- 首版部署在阿里云 99 元/年档位的大陆单机服务器；带宽、内存与磁盘资源有限。
- 预期访问量不确定，按个人小站规模设计，不为高并发预留复杂架构。
- 单人开发与维护，优先减少需要长期照看的组件。
- 预算以服务器约 99 元/年为主，域名等费用按实际采购另计。

## 10. 首版范围边界

### 10.1 首版包含

- 公开首页、文章列表、文章详情、归档、项目列表、项目详情、关于页、404/500。
- 三类固定分类、标签、站内搜索、分类/标签筛选。
- 单管理员登录、退出与后台修改密码。
- 文章草稿、预览、发布、撤回、删除。
- 项目 CRUD 与项目-文章关联。
- 关于页结构化编辑。
- 文章与项目的 Markdown 编辑及图片上传。
- 基础 SEO、复制链接与系统分享。
- 响应式布局与基础可访问性。
- 核心流程自动化测试与 CI。

### 10.2 首版不包含

- 评论、留言、点赞、收藏。
- 访客注册、登录、多作者、多角色权限。
- RSS/Atom 订阅。
- AI 写作、AI 摘要、AI 标签建议。
- 文章版本历史、定时发布、协同编辑、自动保存。
- 媒体库、图片删除、孤儿图片清理。
- 项目草稿/隐藏状态、项目手动排序、项目搜索与筛选。
- 标签独立管理页、标签重命名/合并/删除。
- 文章封面图。
- 数据看板、访问统计、复杂监控与告警。
- 多语言、主题切换、页面搭建器、简历生成器。
- 任何未在本文档列出的功能。
